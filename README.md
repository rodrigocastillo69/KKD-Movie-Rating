Proyecto de minería de datos para clasificar si una película será un éxito o un fracaso financiero utilizando la metodología KDD.

Proceso KDD
Selección y Limpieza: Filtrado del dataset original (~930k registros) eliminando producciones sin datos de presupuesto o recaudación válidos.

Transformación: Procesamiento de géneros, fechas de estreno y preparación de variables predictoras sin fuga de datos.

Modelado: Entrenamiento de algoritmos de clasificación supervisada en Python.

Evaluación: Medición del rendimiento del modelo (Matriz de confusión, F1-Score) e identificación de las variables de mayor impacto.

Datos
Fuente: Dataset en Kaggle

Entorno: Google Colab / Python (Pandas, Scikit-Learn)
